# 中微子研究失败排查与修复

2026-10-07，在真实研究模式下使用题目“中微子的前沿理论”、15 篇论文上限、全部四个来源和中文输出进行验证。

## 失败原因

原任务在阅读阶段返回 `NO_READABLE_PAPERS`。检索已找到 36 篇论文，其中 21 篇有摘要、18 篇有 PDF 地址，但筛选只保留了没有摘要和 PDF 的 Crossref 条目。

真实模型调用确认：`deepseek-flash` 的推理内容耗尽了筛选阶段原有的 2000 token 上限。两批响应以 `finish_reason=length` 结束，分别产生空文本或不完整 JSON。程序仅在所有批次都没有选中论文时回退，因而遗漏了这两批可读论文。阅读阶段又直接对空摘要调用 `.strip()`。

后续报告复核还发现，各论文独立模型调用重复生成 `c1`、`claim-1` 等编号，导致全局证据及引用映射冲突。

## 修复

- 对 DeepSeek 官方接口的混合模型默认使用非推理输出，保留显式推理配置及其他服务商行为。参考 [DeepSeek Thinking Mode](https://api-docs.deepseek.com/guides/thinking_mode/)。阅读摘要也使用统一模型调用入口。
- 将筛选输出预算调整为 4000 token，明确使用批内编号；识别截断、空响应、遗漏和请求失败，逐批补充基于检索词的确定性评分，并保留警告。
- 优先保留已有摘要或 PDF 的相关论文，避免元数据条目挤掉可读证据。
- 容忍缺失摘要；由系统生成包含规范论文 ID 的主张编号，确保跨论文和同一论文内均不重复。
- Streamlit 兼容客户端遵循 `RESEARCH_ENV_FILE`，避免全量测试导入时读取真实 `.env`；修复进程测试读取空 PID 文件的竞争条件，并限制等待时间。

## 结果限制

报告仍标记为部分结果：Semantic Scholar 存在限流；PDF 获取失败时使用真实摘要；未配置嵌入服务；部分模型主张使用直接摘录回退。质量评审尚未通过，报告中的覆盖范围和证据深度仍有不足。引用与证据校验通过不等于研究结论已经获得学术质量认可。

诊断日志、事件、报告和截图位于未追踪的 `artifacts/neutrino-diagnostic/`。全量测试曾因配置隔离缺陷在失败断言中打印本地 API 密钥；本地诊断日志已脱敏，建议轮换该密钥。
