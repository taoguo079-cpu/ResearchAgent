## 剩余问题

### P1 · 部分入口操作的小字对比度不足

- 位置：`components/research/research-entry.module.css:225`、`components/ui/button.tsx:14`、`styles/tokens.css:14`、`components/settings/deepseek-api-key-gate.tsx:123`。
- 研究发送按钮在英文模式使用原始 13px 高的白色字形，在中文模式使用 18px 常规字体；白色对 `#1f80ff` 的对比度为 **3.76:1**，不足普通文本的 4.5:1。浅色 API 配置门禁也使用全局蓝色主按钮，标签为 13px。
- 影响：低视力用户阅读主要操作较困难。对应 WCAG 1.4.3。
- 建议：将这些功能按钮接入已有 `#146be0` 操作色，对比度为 **4.99:1**。原首页品牌字形及此次明确指定的 AGENT 蓝色保留，避免改变用户已选定的视觉元素。
- 对应命令：`$impeccable harden`。

### P1 · 入口语言切换小字偏淡

- 位置：`components/entry/entry.module.css:7`、`components/entry/entry-language-switcher.tsx`。
- 当前 `#70868f` 在白底上为 **3.82:1**，在首页 `#f9fcfc` 背景上为 **3.70:1**。中文界面中的 English 控件使用 13px 实际文本。
- 影响：语言切换操作可见性不足，未满足普通文本的 WCAG 1.4.3 对比要求。
- 建议：采用更深的辅助文字色；同时核对英文界面所使用的原始中文字形素材。
- 对应命令：`$impeccable harden`。

### P2 · 离线提示缺少显式状态通知语义

- 位置：`components/research/task-offline-state.tsx:8`、`components/research/live-task-view.tsx:27`。
- 离线提示根据 online/offline 事件动态出现，但本身是普通 div。相邻的重连提示使用 InlineAlert，具有通知语义。
- 影响：辅助技术未必及时获知独立的离线状态变化；此次没有通过屏幕阅读器实测这一分支。
- 建议：给离线状态补充合适的 `role="status"` 或 polite live region，避免与重连通知重复播报。核对 WCAG 4.1.3。
- 对应命令：`$impeccable harden`。

### P2 · 入口样式存在重复变量与旧菜单规则

- 位置：`components/entry/entry.module.css:18`、`components/entry/research-menu-page.module.css`、`components/research/research-entry.module.css`。
- 新菜单有独立模块；旧 entry 模块中的 menuPage/menuCanvas/pill/robot 布局已不再由菜单引用，该模块仍由语言切换器使用。入口页面还分别重复维护紫色、蓝色、薄荷色。
- 影响：后续修改配色或入口结构时容易遗留旧规则，增加维护成本。目前没有证据表明它们阻断页面运行。
- 建议：清理未使用菜单样式，将确认的入口品牌色集中到公共变量；入口固定浅色的设计继续显式保留。
- 对应命令：`$impeccable extract`。
